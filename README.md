# אתרי תרבות ומורשת בעמק יזרעאל

מפה אינטראקטיבית ציבורית של אתרים ארכאולוגיים, אתרים היסטוריים ומוסדות תרבות פעילים בתחום השיפוט של **מועצה אזורית עמק יזרעאל**, מטעם [המכון הישראלי למדיניות תרבות](https://iicp.org.il).

לכל נקודה במפה יש מקורות מזוהים, צירי סטטוס, רמת ודאות מחושבת ויומן טענות שמראה מה כל מקור אמר, כולל הערכים שנדחו.

## שלוש הקטגוריות

חוק העתיקות התשל"ח-1978 מגדיר עתיקות כשרידים שנוצרו לפני שנת 1700, ולכן 1700 היא הקו שמפריד בין שתי הקטגוריות הראשונות:

| קטגוריה | הגדרה | הגוף המוסמך |
|---|---|---|
| אתר ארכאולוגי | עד 1700 | רשות העתיקות |
| אתר היסטורי | אחרי 1700 | המועצה לשימור אתרי מורשת בישראל |
| מוסד תרבות ואומנות | פעיל כיום | המוסד עצמו, משרד התרבות |

אתר יכול להיות בכמה קטגוריות בבת אחת, למשל מוזיאון שיושב בתוך אתר ארכאולוגי, והמסננים מתייחסים לכולן. אנשים בודדים אינם נכללים במפה.

## פרטיות

`src/redact.py` הוא שער יחיד שכל תוצר שמתפרסם עובר בו. **כתובת דואר אלקטרוני אינה מתפרסמת בכלל**, טלפון מתפרסם רק לגוף מוסדי מובהק, יומן הטענות מושחר לכל רשומה, וכל מחרוזת נסרקת כי כתובות יושבות גם בתוך פרוזה. הארכיון הקפוא מושחר לפני הדחיסה, כולל הסרת 81 שורות של אנשים פרטיים. `src/audit.py` נכשל אם כתובת נותרה בתוצר.

`data/out/` אינו במעקב גיט, כי הוא המאגר שלפני ההשחרה. התוצרים שמתפרסמים הם `site/data/`.

הרקע המלא, כולל תקלה שקרתה ומה עוד דורש הכרעה: [`docs/00-state.md`](docs/00-state.md).

## תוספות ידניות

`data/manual/additions.json` הוא הבית לנתונים שאדם הוסיף ולא ניתן לשחזר אותם מהרצת הצינור, ולכן הוא נשמר בגיט. כל רשומה נושאת מי מסר אותה, מאיפה ומתי. רשומה שהשם והמיקום שלה מתאימים לאתר קיים מתמזגת אליו ותורמת לו שמות, תקופות וסטטוסים; רשומה שאינה מתאימה לאף אתר הופכת לאתר חדש. שתי ההתנהגויות נובעות מאותו מנוע התאמה, ולכן שום דבר כאן לא עוקף אותו.

הוספה חדשה: לערוך את הקובץ ולהריץ `python src/adapters.py && python src/harmonize.py && python src/build_site.py`.

**עמוד ענן אינו נכלל בשליפה אוטומטית.** ההבהרה המשפטית של האתר אוסרת במפורש הורדת חומר על ידי מכונה, והחריג היחיד בה הוא אינדקס לא-גיאוגרפי של מנועי חיפוש גדולים. הנתונים שנשלפו לפני שההגבלה זוהתה נמחקו. הדרך הלגיטימית היחידה היא אישור בכתב מבעל האתר. הפירוט המלא ב-`docs/sources/amudanan.md`.

עובדות מעמוד ענן כן נכנסות למפה כאשר **אדם מסר אותן ידנית**, דרך `data/manual/additions.json`. גם אז נרשמות העובדות בלבד והתיאור נכתב מחדש, כי התוכן שם שמור בכל הזכויות.

## שלושה עקרונות

1. **המאגר שומר טענות ולא עובדות.** לכל ערך שנפתר יש `provenance` עם מזהי המקורות שתומכים בו, וכל הטענות הגולמיות נשמרות ב-`claims` כולל אלה שהפסידו.
2. **מקור אחד לאמת לכל שדה, כתוב מראש.** `schema.PRECEDENCE` קובע איזה מקור מנצח בכל שדה בנפרד, כי הסמכות משתנה לפי השדה. בשדות של סטטוס משפטי, ערך ממקור שאינו הסמכות נזרק ולא נכנס.
3. **פער מוצהר עדיף על ניחוש.** לכל ציר סטטוס יש `unknown` מפורש, והמפה מציגה אותו ומודדת אותו.

## הפרויקט בהקפאה

הוקפא 4.8.2026. המפה חיה ועומדת בפני עצמה. **נקודת הכניסה למי שחוזר: [`docs/00-state.md`](docs/00-state.md)** — מה עומד, מה לא נעשה, מה השאריות המתועדות, ואיזה החלטות לא כדאי לבטל בלי לקרוא קודם.

## הרצה

```
python src/test_core.py      # בדיקות ליבה
python src/adapters.py       # מקורות -> data/interim/*.claims.json
python src/harmonize.py      # התאמה, מיזוג, ניקוד -> data/out/sites.json
python src/audit.py          # בדיקה עצמית דטרמיניסטית
python src/build_site.py     # -> site/data/
python -m http.server 8765 --directory site
```

דורש Python 3.12 ומעלה עם pandas, geopandas, shapely, pyproj, openpyxl, requests, rapidfuzz.

**שכפול טרי של הריפו יכול לבנות את המפה מחדש.** `data/raw/` (336 מ"ב הורדות מקוריות) ו-`data/interim/` (83 מ"ב מטענים מנורמלים) מוחרגים מגיט, ולכן `data/frozen/` מחזיק את הקלט שהצינור קורא בדחיסת gzip, 6.9 מ"ב, והוא כן נשמר. `src/paths.py` מגשר על שני המצבים ואף קורא אינו צריך לדעת באיזה מהם הוא נמצא. `data/out/` נשמר, כי המאגר המאוחד הוא התוצר.

המקורות הגולמיים עצמם אינם בגיט, אבל `docs/sources/*.md` מתעד לכל אחד את נקודות הקצה המדויקות והסכמה המלאה, ולכן אפשר לשלוף אותם מחדש.

## מה עוד לא נעשה

- **סבב האימות מרובה הסוכנים לא רץ.** הוא נכתב במלואו והופעל, אבל כל עשרת הסוכנים נכשלו על מגבלת שימוש בסשן, ומתן החליט לוותר עליו. המשמעות: **הודאות במפה מחושבת ואינה מאומתת מול מקורות חיצוניים נקודה-נקודה.** הבדיקה העצמית (`src/audit.py`) כן עוברת בלי אף מפגע חמור. הסקריפט שמור ב-`workflows/02-verification.js` ואפשר להריץ אותו כמו שהוא.
- 30 זוגות נקודות שייתכן שהן אותו מקום ולא אוחדו, מתועדים ב-`data/out/audit.json`.
- 22 נקודות מוצגות בשם באנגלית, כי אף מקור שנבדק לא נותן להן שם עברי. רובן מערות הקבורה בבית שערים. לא הומצא להן שם.
- 622 רשומות חפירה של רשות העתיקות אינן מציינות אתר ולכן לא הפכו לנקודות. חפירה היא אירוע ולא מקום.
- פעילות של מוסדות תרבות ידועה ב-27 מתוך 116.

הפירוט המלא, כולל ההחלטות שלא כדאי לבטל בלי לקרוא קודם: [`docs/00-state.md`](docs/00-state.md).
