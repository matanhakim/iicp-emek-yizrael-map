# ארכיון קלט קפוא

הקבצים כאן הם הקלט שהצינור קורא, דחוסים ב-gzip ונשמרים בגיט. המקורות הגולמיים המקוריים, כ-336 מ"ב, אינם בגיט; מה שמתועד עליהם נמצא ב-`docs/sources/`, כולל נקודות הקצה המדויקות לשליפה חוזרת.

הקוד קורא את הקבצים האלה אוטומטית דרך `src/paths.py` כאשר `data/interim/` ו-`data/raw/` אינם קיימים, ולכן שכפול טרי של הריפו יכול לבנות את המפה מחדש:

```
python src/adapters.py && python src/harmonize.py && python src/build_site.py
```

לרענון הארכיון מתוך עותק עבודה: `python src/freeze.py`.
